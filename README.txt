JIA MIN LITTLE LUCKY LAB

This is an installable PWA, not an APK.
1. Upload the entire contents of this folder to a HTTPS static web host (e.g. GitHub Pages or Netlify).
2. Open its HTTPS URL on Samsung Internet or Chrome and choose Install app / Add to Home screen.
3. App automatically checks the playingmeow GitHub CSV when opened, and the Refresh button checks again. The source updates by noon the day AFTER draws, not instantaneously.
4. Offline: bundled historical data and saved favourites work; latest results require internet.
5. Browser cross-origin access to GitHub raw CSV is subject to network/browser policy; check actual hosting. If blocked, deploy a server-side proxy.
6. Historical data rows sometimes differ from the current 23-prize format; historical category labels for unusual older draws may be inaccurate.
7. The app does not send push notifications while closed and is not published or hosted yet.
8. Personal notebook is stored on-device via localStorage; export regularly.
